# 아버지를 위한 축의금 조회

아버지가 누군가에게 축의금을 얼마나 받았는지 확인할 때마다 컴퓨터를 켜고, 엑셀 파일을 찾아 열고, 이름을 하나씩 살펴보는 과정이 있었습니다. 금액을 확인하는 일보다 파일을 찾고 열어 원하는 사람을 다시 찾는 과정이 더 번거롭고 시간을 잡아먹었습니다.

이 프로젝트는 그 반복을 줄이기 위해 만들었습니다. 배포가 끝나면 아버지는 조회 페이지를 열어 이름을 검색하고, 해당하는 기록과 금액을 바로 확인할 수 있습니다.

## 달라지는 점

- 컴퓨터에서 엑셀 파일을 찾아 여는 단계를 줄입니다.
- 이름 검색으로 필요한 기록을 빠르게 찾습니다.
- 검색 결과에서 이름과 금액을 한눈에 확인합니다.
- 같은 이름을 가진 분들의 기록도 각각 따로 확인할 수 있습니다.
- 결과는 한 번에 10명씩 보여 필요한 내용을 차례로 살펴볼 수 있습니다.

## 만든 이유

축의금 기록은 필요할 때 바로 찾아볼 수 있어야 합니다. 매번 같은 파일을 열고 다시 검색하는 과정이 조회의 병목이 되지 않도록, 아버지가 기억을 확인하는 일을 간단한 검색 한 번으로 끝낼 수 있게 하는 것이 목적입니다.

화려한 기능보다 아버지가 부담 없이 열어보고 바로 이해할 수 있는 화면을 우선했습니다. 기술 자체를 보여주기보다, 반복되는 수고를 덜어드리는 데 집중했습니다.
