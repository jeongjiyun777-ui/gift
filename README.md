# 정정식 업무모음

아버지가 매번 컴퓨터를 켜고 엑셀 파일을 찾아보던 일을, 휴대폰에서 기록을 조회하고 입력하는 흐름으로 바꾼 개인 업무 관리 서비스입니다. 축의금 조회로 시작해 지출금액, 운행, 요소수·경유, 차량 수리 기록까지 한곳에서 관리하도록 확장했습니다.

## 해결하고 싶었던 반복 업무

누가 얼마를 냈는지 확인하려면 엑셀 파일을 열고 이름을 찾아야 했습니다. 운행 명세서와 영수증도 따로 관리하다 보니 한 달 동안 벌어들인 금액과 지출을 파악할 때마다 자료를 모으고 합산하는 과정이 필요했습니다.

개별 계산보다 자료를 찾고, 다시 입력하고, 같은 기준으로 정리하는 과정이 업무를 지연시켰습니다. 필요한 기록을 바로 찾고 입력된 데이터를 다시 활용하도록 만드는 데 집중했습니다.

## 달라진 업무 흐름

| 기존 과정 | 서비스에서 처리하는 방식 |
| --- | --- |
| 컴퓨터를 켜고 엑셀에서 이름 찾기 | 휴대폰에서 이름을 검색해 받은 금액과 지출금액 확인 |
| 운행·주유·수리 내역을 파일별로 확인 | 업무별 입력·조회 화면에서 기록 관리 |
| 영수증의 내용을 직접 옮겨 적기 | 요소수·경유 영수증을 촬영해 입력값을 채우고, 확인 후 저장 |
| 단가와 수량을 곱하고 금액을 다시 입력 | 요소수·경유의 단가와 수량으로 총액 자동 계산 |
| 한 달 자료를 골라 합계와 세액 계산 | 선택한 월의 기록으로 공급가액·세액·총액 집계 |
| 월별 수입과 여러 종류의 지출을 따로 합산 | 간편보기에서 운행 공급가액과 지출 공급가액을 비교 |
| 정리한 내역을 엑셀로 다시 작성 | 운행·요소수·경유 기록을 엑셀로 다운로드 |

## 주요 기능

- **받은 금액·지출금액**: 이름 검색, 입력, 삭제, 동명이인 기록 구분. 지출은 날짜·목록·세부사항·장소를 함께 관리합니다.
- **운행**: 날짜, 화주, 출발지·도착지, 거리, 컨테이너 번호와 공급가액을 기록하고 월별로 조회·수정·삭제합니다.
- **요소수·경유**: 영수증 사진 인식, 단가와 수량에 따른 총액 계산, 월별 금액과 사용량 합계를 제공합니다.
- **차량 수리**: 업체, 사업자번호, 카드사, 할부 개월과 총액을 관리합니다. 월 할부금을 계산하고 반올림 차이는 마지막 회차에서 조정합니다.
- **간편보기**: 운행 공급가액에서 요소수·경유·수리의 공급가액을 차감하고, 매출세액·매입세액과 차감 후 예상 세액을 표시합니다. 각 기록의 날짜를 기준으로 집계하며 수리비는 할부 납입액이 아닌 수리 내역의 금액을 반영합니다.
- **휴대폰 사용**: 홈 화면에 추가해 앱처럼 열 수 있습니다. 저장 성공 후에는 해당 조회 화면으로 이동합니다.

## 사용자를 기준으로 정한 화면

아버지가 필요한 작업을 쉽게 찾도록 조회와 입력 메뉴를 나눴습니다. 월을 선택한 뒤 기록을 보여주고, 표는 가로로 넘겨 전체 내용을 볼 수 있게 했습니다. 저장 중 버튼을 잠그고 삭제 전에 확인을 받아 연속 입력이나 실수로 기록을 지우는 일을 줄였습니다.

영수증 인식 결과는 바로 저장하지 않습니다. 입력폼에 채운 내용을 사용자가 확인한 뒤 저장하게 했습니다.

## 검증

`backend/test_*.py`에 저장·조회·수정·삭제와 금액 계산 테스트를 포함했습니다. 월 경계의 기록 포함 여부, 여러 테이블 집계 시 금액 중복, 부가세 반올림, 할부 마지막 회차 조정, 없는 기록 삭제 시 전체 취소 등을 확인합니다. 테스트는 임시 DB와 모의 연결을 사용해 운영 데이터를 변경하지 않습니다.

프로젝트 폴더에서 실행합니다.

```powershell
python -m unittest discover -s backend -p "test*.py" -v
```

## 구성

- 화면: Next.js, TypeScript, Tailwind CSS
- 서버: FastAPI, SQLAlchemy
- 데이터: PostgreSQL, Neon
- 영수증 인식: Gemini
- 배포: Vercel, Render

테이블 정의는 `db/schema.sql`, 기존 DB 변경 이력은 `db/migrations/`에서 관리합니다. 실제 연결 정보는 서버 환경변수로 설정하며, `.env.example`은 필요한 설정의 예시입니다.
